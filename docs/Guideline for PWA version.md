# PWA機能の追加

## 概要
- PWA機能を追加し、スマートフォンでの利用体験を向上させる
- リマインダー機能を追加する
  - PWAでの利用の場合、AzureIDと連携することで各スケジュールをマークしておくことができる。
  - マークしたスケジュールは開始の1時間前にプッシュ通知を送る。

## 実装計画

### 現状分析
- ✅ 基本PWA機能：manifest.json、Service Worker実装済み
- ❌ AzureID連携：未実装（新規開発が必要）
- ✅ スケジュールデータ：JSON形式で管理済み
- ✅ バックエンド基盤：Go + Gin、定期更新機能あり

### 実装フェーズ

#### Phase 1: ユーザー識別機能
- ローカルストレージでユーザーID管理
- スケジュールマーク機能のUI追加
- マーク情報の保存・取得API

#### Phase 2: プッシュ通知基盤
- VAPID キー生成・設定
- Service Workerのpushイベント拡張
- プッシュ通知許可取得UI

#### Phase 3: リマインダー機能
- 1時間前通知の定期チェック機能
- Go側でのプッシュ通知送信実装
- 通知クリック時の動作設定

#### Phase 4: UI/UX改善
- マークボタンの追加
- 通知設定画面
- リマインダー一覧表示

### 技術要件
- HTTPS必須（プッシュ通知のため）
- web-push-goライブラリ使用
- ブラウザ対応確認（Chrome, Firefox, Safari等）

### 実現可能性
**結論：実現可能** ✅
既存のPWA基盤を活用し、段階的な実装により実現可能。
